# وایبچه (Vibeche) — تمرین اول درس برنامه‌سازی وب

پروژه وب‌اپلیکیشن فروشگاه و مطالعه آنلاین کتاب **«وایبچه» (Vibeche)** با الهام از وب‌سایت طاقچه ([taaghche.com](https://taaghche.com))، پیاده‌سازی شده برای **تمرین اول درس برنامه‌سازی وب** (نیم‌سال پاییز ۱۴۰۵، دانشگاه صنعتی شریف — استاد محترم درس: جناب آقای دکتر علی ابریشمی).

* **نام دانشجو:** عرفان بهلول
* **شماره دانشجویی:** ۴۰۲۱۰۵۷۷۳ (402105773)

---

## ۱. ویژگی‌ها و مشخصات فنی

- **فناوری‌های پایه (Vanilla Web)**: صرفاً با استفاده از **HTML5**, **CSS3** و **JavaScript (ES6+)** خام؛ بدون استفاده از هرگونه فریم‌ورک (مانند React, Vue)، کتابخانه کمکی (مانند jQuery)، قالب‌های آماده یا CDN خارجی.
- **کاملاً آفلاین و مستقل**: بدون وابستگی به هیچ‌گونه سرور پشتیبان، پایگاه‌داده شبکه، درگاه پرداخت یا اینترنت. برنامه بلافاصله پس از باز کردن فایل در مرورگر اجرا می‌شود.
- **طراحی راست‌به‌چپ (RTL) و فارسی**: استفاده از تایپوگرافی اصیل فارسی، اعداد فارسی، چینش و پالت رنگی هماهنگ با هویت بصری طاقچه.
- **معماری تک‌صفحه‌ای (SPA) مبتنی بر URLSearchParams**: تمامی صفحات (صفحه اصلی، کاتالوگ و جستجو، جزییات کتاب، کتابخانه شخصی و نمونه‌خوان) با هماهنگی کامل مرورگر و نشانی URL قابل بازنشانی (Reloadable) و اشتراک‌گذاری هستند.
- **مدیریت وضعیت با LocalStorage بر پایه حساب کاربری**:
  - ایزوله‌سازی کامل داده‌ها برای هر شماره موبایل (`vibeche_account_09...`)؛
  - ماندگاری قطعی اطلاعات علاقه‌مندی‌ها و کتابخانه پس از خروج از حساب؛
  - عدم شمارش مضاعف (Deduplication) کتاب‌های مشترک بین علاقه‌مندی‌ها و کتابخانه؛
  - بازیابی امن در صورت خرابی یا نارسایی داده‌های ذخیره‌شده.
- **نمونه‌خوان اختصاصی کتاب با تم مستقل**:
  - پشتیبانی از ۳ اندازه قلم (کوچک، متوسط، بزرگ)؛
  - ۳ تم اختصاصی خواندن (روشن / روز، کاغذی / سپیا، تیره / شب) با ماندگاری در LocalStorage؛
  - تفکیک کامل تم صفحه مطالعه از قالب کلی فروشگاه (سایت همواره در حالت روشن و استاندارد طاقچه باقی می‌ماند).
- **واکنش‌گرایی (Responsive Design)**: پشتیبانی روان از نمایشگرهای موبایل (360px)، تبلت (768px) و دسکتاپ (1440px) بدون اسکرول افقی ناخواسته.
- **دسترس‌پذیری (Accessibility)**: برچسب‌گذاری کامل ورودی‌ها، متن‌های جایگزین تصویر (`alt`)، استایل‌های فوکوس صفحه‌کلید (`:focus-visible`) و بستن پنجره‌های بازشو با کلید `Escape`.

## ۲. مسیر شروع و روش اجرا (Quick Start)

این پروژه نیاز به نصب هیچ‌گونه وابستگی (`npm install`)، راه‌اندازی سرور، یا اتصال اینترنت ندارد.

### روش ۱: اجرای مستقیم در مرورگر (پیشنهادی)
کافی است فایل `index.html` را با دو بار کلیک یا باز کردن مستقیم در مرورگر مورد نظر خود اجرا کنید:
```bash
# در سیستم‌عامل macOS:
open index.html

# در سیستم‌عامل Linux:
xdg-open index.html

# در سیستم‌عامل Windows:
start index.html
```

### روش ۲: اجرای از طریق سرور محلی سبک (اختیاری)
در صورت تمایل به اجرای روی Localhost:
```bash
# با استفاده از پایتون ۳:
python3 -m http.server 8000

# سپس باز کردن آدرس در مرورگر:
# http://localhost:8000/index.html
```

## ۴. روش پاک کردن وضعیت ذخیره‌شده (Reset State)

برای بازنشانی سامانه به وضعیت اولیه کارخانه و آزمون از نو، سه روش سریع در نظر گرفته شده است:

### روش ۱: استفاده از کلید بازنشانی داخل سامانه (آسان‌ترین روش)
در پابرگ (Footer) تمامی صفحات سایت، دکمه‌ای با عنوان **«بازنشانی داده‌های ذخیره‌شده (ریست سامانه)»** قرار داده شده است. با کلیک بر روی آن و تأیید پنجره بازشو، کلیه حساب‌های کاربری، علاقه‌مندی‌ها، خریدهای شبیه‌سازی‌شده و تنظیمات مطالعه پاکسازی شده و صفحه مجدداً بارگذاری می‌شود.

### روش ۲: از طریق کنسول مرورگر (Developer Tools)
کلید `F12` (یا `Cmd + Option + I`) را فشرده، وارد تب `Console` شوید و دستور زیر را اجرا کنید:
```javascript
VibecheStorage.clearAll();
location.reload();
```

### روش ۳: پاکسازی حافظه محلی مرورگر
در کنسول مرورگر دستور زیر را اجرا کنید:
```javascript
localStorage.clear();
location.reload();
```
